# Moonlight Birthday Journey --- Premium Interactive Birthday Website Prompt

## Objective

Create a fully responsive, **mobile-first**, premium interactive
birthday website for **Priyanka**. The experience should feel like a short
magical journey instead of a normal birthday webpage.

Core emotions:

Curiosity → Discovery → Wonder → Surprise → Celebration

The website should feel: - Premium - Cute - Cinematic - Interactive -
Smooth - Playful - Memorable

Avoid: - Hacker aesthetics - Generic loading screens - Clutter -
Cheap-looking gradients - Aggressive animations

------------------------------------------------------------------------
