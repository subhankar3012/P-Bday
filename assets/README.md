# Assets Directory

This directory contains all project assets organized by type.

## Structure

```
assets/
├── images/    — Photos, illustrations, backgrounds
├── audio/     — Music, sound effects
├── icons/     — UI icons, favicons
└── fonts/     — Custom typefaces
```

## Notes

- All assets will be added in future layers
- Image assets should be optimized for mobile (WebP preferred)
- Audio files should be in MP3/OGG format for cross-browser support
- Icons should be SVG where possible
